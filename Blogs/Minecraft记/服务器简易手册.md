# 服务器简易使用手册

## 核心功能直达

- `/rtp`：方圆千里**随机传送**
- `/tpa <其他玩家>`：请求把自身**传送到其他玩家位置**
- `/tpahere <其他玩家>`：邀请其他玩家**传送到自身位置**（注意！不要打少这个 a）
- `/mvtp <世界名字>`：把自己**传送到某世界**（传送到当前所在的世界会直接传回出生点），目前支持的世界名字：
	1. `starhi`：默认的纯生存世界 
	2. `reds`：创造模式的超平坦世界
	3. `pcity`：网上拿的好看地图可以捉迷藏
- `/mvlist`：列出可以传送的世界信息
- `/veinminer toggle`：**开关自动挖矿**
- `/treefeller toggle`：**开关自动砍树**
- `/fp`：假人命令
	1. 你可以召唤假人来帮你保持区块加载、怪物刷新
	2. 大部份命令都可以对这些假人生效，因为他们对于服务器来说就是"真实的"玩家
	3. 你可以使用假人的背包来存放物品，但是假人删除后会自动把物品弹出。
	4. 你可以控制假人执行一些动作比如: 跳跃、攻击、进食、睡觉等等。不仅如此，你还可以将这些行为设置为周期性的。
	5. 发挥你的想象～
- `/fp spawn`：在自身位置**召唤假人**（注：首次召唤可能会被踢或要等一段时间才有反应，被踢重新召唤一次即可）
- `/back`：回到上一个位置（死亡后回到死亡点）

- `tab`：按住 tab 键可以查看服务器信息＋在线玩家＋ping＋当前时间＋TPS/MSPT＋
- `表情工艺（Emotecraft）`：为 JAVA 版添加了类似基岩版的人物动态表情！
- `Grave`：墓碑插件，死亡后在死亡位置生成保留时间为 7 min 的人头墓碑
	- 对着人头**右键**可以看/取物品
	- **Shift+右键**可以一键取出东西
- `网上 BlueMap`：在浏览器访问服务器的 8100 端口可以查看服务器已加载的全部地图
 	- [BlueMap](http://8.138.203.139:8100/)
- `网上统计数据`：在浏览器访问服务器的 8804 端口可以查看服务器的统计数据
 	- [Plan](http://8.138.203.139:8804/)
- `支持基岩版`：使用 Geyser 支持基岩版玩家登录

## 游戏内语音

服务器同时支持 [Plasmo Voice - Minecraft Plugin](https://modrinth.com/plugin/plasmo-voice) 和 [Simple Voice Chat - Minecraft Plugin](https://modrinth.com/plugin/simple-voice-chat) 两种语音插件 ^vcplu
但是这并**不能**让使用了不同语音插件客户端互相语音通话
服务器里面的玩家如果希望游戏内语音交流的, 应当在客户端安装上述两种语音 MOD 中的**一种**，不应同时安装
然后游戏内两个插件的**快捷键都是 v**
**推荐使用 Simple Voice Chat** ^18a23f

### Plasmo Voice 如何全图无视距离交流

你可以使用**群组功能**

#### 基本使用方法

**创建群组并邀请玩家：**

1. 按 **V** 键打开 Plasmo Voice 菜单（默认快捷键）
2. 进入 **激活** 选项卡，配置 **群组** 激活设置
3. 使用命令创建群组：`/groups create [参数...]`
4. 邀请玩家加入群组：`/groups invite <玩家名>`
5. 使用激活设置即可在群组中语音聊天

**浏览群组：**

- 使用命令浏览公开群组：`/groups` 或 `/groups browse`

#### 创建群组参数说明

创建群组时可以使用以下参数（所有参数都是可选的，顺序不限）：

- `name:` - 群组名称
- `password:` - 群组密码
- `persistent:` - 设置为 `true` 时，群组在空员或服务器重启后不会自动删除
- `permissions:` - 只允许拥有特定权限的玩家加入，可设置多个权限（用逗号分隔）

**示例：**

```sh
/groups create name: 兄弟们 password: 123456 persistent: true permissions: group.brothers
```

这个命令会创建一个名为"兄弟们"的群组，密码为"123456"，群组会持久保存，只有拥有 `group.brothers` 权限的玩家才能加入。

## 通用注意事项

1. 所有插件指令需确保输入正确才可使用；
2. 语音聊天需确保客户端安装对应插件 [[#^vcplu]]，否则无法使用；
3. 遇到皮肤显示异常、背包丢失、传送问题等，可优先使用对应插件指令排查（如`/skins`、`/graves`、`/home`）；
4. 禁止恶意作弊，GrimAC会实时检测，违规将被处罚。

## 常见问题

1. 无法连锁：转开头/联系管理员；
2. 登录失败：联系管理员；
3. 语音无声音：确定**客户端 MOD 安装正确**；检查客户端语音设置、麦克风权限；确认处于正确的语音频道；
4. 跨版本连接失败：确保客户端版本在服务器支持范围内/确保不要使用什么奇奇怪怪的**整合包端**数据包端进入。
